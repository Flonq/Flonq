## CURRENTLY BUILDING

### UAV Flight Simulator

A fixed-wing UAV simulation project built in **Unity 6.3 LTS** and **C#**, focused on modular flight systems, physics-driven control, mission flow and ground-control-style telemetry.

The project is being developed system by system rather than relying on a prebuilt flight framework. The current development phase is moving into the **engine and throttle system**, followed by core flight physics, camera, telemetry and mission systems.

`Unity 6.3 LTS` · `C#` · `Unity Physics` · `Input System` · `URP` · `Git`

> Repository publication is planned after third-party asset redistribution requirements are fully reviewed.
